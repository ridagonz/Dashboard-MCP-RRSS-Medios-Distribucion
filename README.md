# Dashboard Contenidos API SIMIT

Tablero de resultados de los contenidos API SIMIT (23 al 29 de octubre de 2026): onda expansiva, interacciones, difusión, contenidos y reproducciones de video.

## Ver el tablero
- **En local:** abre `index.html` en el navegador.
- **En GitHub Pages:** Settings → Pages → Branch `main` / carpeta raíz. Queda publicado en `https://<usuario>.github.io/<repositorio>/`.

## Actualizar las cifras
Edita el bloque `window.DATOS` dentro de `index.html`. La carpeta `data/` guarda los mismos valores en JSON como respaldo.

## Tecnología
HTML, CSS y [d3 v7](https://d3js.org/) desde CDN. Sin dependencias ni compilación.
